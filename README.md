## 🌐 Hosting on GitHub Pages

Follow these steps to host your CS Quest website on GitHub Pages for free:

### Step 1: Create a GitHub Repository

1. Go to [GitHub.com](https://github.com) and sign in
2. Click the **"+"** icon in the top right and select **"New repository"**
3. Name your repository (e.g., `cs-quest`)
4. Add a description: "Interactive Computer Science Learning Platform"
5. Choose **Public** (required for free GitHub Pages)
6. Click **"Create repository"**

### Step 2: Upload Your Files

#### Option A: Using Git Command Line

```bash
# Initialize git in your project folder
git init

# Add all files
git add .

# Commit the files
git commit -m "Initial commit: CS Quest learning platform"

# Add your GitHub repository as remote
git remote add origin https://github.com/yourusername/cs-quest.git

# Push to GitHub
git branch -M main
git push -u origin main
```

#### Option B: Using GitHub Web Interface

1. In your new repository, click **"uploading an existing file"**
2. Drag and drop `index.html` and `README.md`
3. Click **"Commit changes"**

### Step 3: Enable GitHub Pages

1. In your repository, click **"Settings"**
2. In the left sidebar, click **"Pages"**
3. Under **"Source"**, select **"Deploy from a branch"**
4. Under **"Branch"**, select **"main"** and **"/ (root)"**
5. Click **"Save"**

### Step 4: Access Your Website

Your site will be published at:
```
https://yourusername.github.io/cs-quest/
```

**Note:** It may take 1-2 minutes for your site to become available after enabling GitHub Pages.

### Step 5: Update Your Site (Optional)

To make changes:

```bash
# Make your edits to index.html

# Add and commit changes
git add index.html
git commit -m "Update learning content"

# Push to GitHub
git push origin main
```

Your GitHub Pages site will automatically update within a few minutes!

## 🎨 Design System

### Color Palette
```css
Neon Cyan:    #00ffff  /* Primary accent, interactive elements */
Neon Magenta: #ff00ff  /* Secondary accent, highlights */
Neon Yellow:  #ffff00  /* Tertiary accent, titles */
Deep Purple:  #1a0033  /* Dark background elements */
Mid Purple:   #2d0052  /* Card backgrounds */
Dark BG:      #0a0014  /* Main background */
```

### Typography
- **Display Font:** Press Start 2P (retro gaming aesthetic)
- **Body Font:** Space Mono (monospace, clean and readable)

### Animation Principles
- **Entrance Animations:** Fade-in with slide-up (0.6s ease-out)
- **Hover Effects:** Subtle lift and glow (0.3-0.4s transitions)
- **Background Motion:** Continuous grid scroll, floating orbs
- **Staggered Delays:** Cards animate sequentially for visual interest

## 📖 Usage Guide

### For Learners

1. **Browse Topics:** Scroll through the topic cards or use filters to find topics by difficulty
2. **Search:** Type keywords in the search bar to quickly find specific concepts
3. **Learn:** Click any topic card to open a detailed modal with:
   - Clear explanations
   - Real-world analogies
   - Key concepts
   - Code examples
   - Interactive demos
4. **Practice:** Click "Try It Out!" buttons to run interactive code demonstrations
5. **Track Progress:** Note the estimated duration for each topic

### For Educators

This platform can be used to:
- Introduce CS concepts to non-technical students
- Supplement traditional CS curriculum with visual aids
- Provide interactive homework resources
- Create a self-paced learning environment
